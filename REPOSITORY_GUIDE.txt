THE ARCHITECTURE (How It Works)
================================================================================

PHONE FLOW:
  Customer calls → Twilio receives → Routes to your server via webhook →
  Your agent processes → Saves to database → Contractor sees on dashboard

AGENT COORDINATION:
  Lead Agent → Database ← Quote Agent
  Schedule Agent → Database ← Billing Agent
  (All agents read/write same PostgreSQL DB, no direct agent-to-agent calls)

OWNER APPROVAL:
  Agent suggests → Owner reviews → Owner approves → Agent executes
  (Human-in-the-loop at every critical step)

TECH STACK:
  Frontend: Next.js + React (contractor dashboard)
  Backend: FastAPI (Python web server)
  AI: LangChain + GPT-4 (agent orchestration)
  Database: PostgreSQL (central data hub)
  Voice/SMS: Twilio (phone calls + text messages)
  Payments: Stripe (invoice processing)
