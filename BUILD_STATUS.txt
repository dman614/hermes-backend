HOW TO RUN IT RIGHT NOW
================================================================================

1. Navigate to backend:
   cd /media/Dman/Hermes/Hermes/backend

2. Add your OpenAI API key:
   nano .env
   # Update: OPENAI_API_KEY=sk-proj-YOUR-KEY-HERE
   # Save: Ctrl+X, Y, Enter

3. Start the server:
   bash run.sh

4. Test it (in another terminal):
   curl -X POST http://localhost:8000/api/test/transcript \
     -H "Content-Type: application/json" \
     -d '{"transcript": "Emergency plumbing at 123 Main St"}'

5. Expected response:
   {
     "success": true,
     "extracted": {
       "service_type": "plumbing",
       "urgency": "emergency",
       "address": "123 Main Street",
       "customer_phone": "+1-250-555-1234"
     },
     "confidence": 0.85
   }
