# Deployment & Model Selection: Quick Summary

**Your Questions:**
1. How do you deploy agents to contractors?
2. Claude or DeepSeek?

**Answers:**
1. Cloud SaaS (AWS). Bob just opens browser.
2. Claude for MVP. DeepSeek for scale (10x cheaper).

---

## Deployment: Cloud SaaS, Not Local Installation

### Wrong Way (Local Installation)
```
❌ Install software on each contractor's computer
❌ Each Bob has separate database (data spread everywhere)
❌ Hard to update (100 contractors = 100 separate updates)
❌ Hard to support (each installation is different)
❌ Security nightmare (API keys on Bob's computer)
```

### Right Way (Cloud SaaS)
```
✅ One cloud backend (AWS)
✅ Bob opens browser: https://hermes.app
✅ One database (all 100 contractors share)
✅ Automatic updates (everyone gets new features instantly)
✅ Secure (AWS Secrets Manager for API keys)
✅ Scalable (1 backend serves 1,000 contractors)
✅ Available 24/7 (AWS redundancy)
```

---

## Architecture: AWS Stack

```
Internet → CloudFlare CDN → AWS Load Balancer → ECS Containers
                                                   ├── FastAPI API
                                                   ├── 4 Agents
                                                   └── Auto-scaling (2-10)
                                                         ↓
                                            ┌──────────────────┐
                                            │ RDS PostgreSQL   │
                                            │ (shared database)│
                                            └──────────────────┘

Bob accesses via:
  1. Web: https://hermes.app (any browser)
  2. Mobile: iOS/Android app (push notifications)

Data completely isolated:
  Bob (Contractor 1) sees only his data
  Sarah (Contractor 2) sees only her data
  No data leakage between contractors
```

## Onboarding: 5 Steps

```
1. Bob signs up: Email, password, business name
2. Hermes creates contractor account
3. Bob connects external services:
   ├── Twilio (forward his business number)
   ├── QuickBooks (OAuth login)
   └── Stripe (for payments)
4. Bob invites his techs (Sarah, Mike)
5. System ready (all data isolated & secure)
```

## Recommendation: Hybrid Strategy

### Phase 1: MVP (Weeks 1-12) → USE CLAUDE
```
✅ Better reasoning (fewer errors)
✅ Faster to market
✅ Production-proven
Cost: $2,304/year (negligible)
```

### Phase 2: Scale (Month 6) → EVALUATE DEEPSEEK
```
After: 20-50 paying customers
Test: Claude vs DeepSeek accuracy
If: DeepSeek >90%, switch
Save: $2,285/year
```

### Phase 3: Optimize (Year 2) → SELF-HOST OR HYBRID
```
Option 1: Self-host DeepSeek (zero API costs)
Option 2: Fine-tune DeepSeek (better accuracy)
Option 3: Hybrid (Claude for quotes, DeepSeek for bulk)
Cost: $50-500/month (your choice)
Margins: Maximum
```
